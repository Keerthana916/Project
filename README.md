## Project Highlights

### Cell Phone Price Range Prediction
* **Outcome:** Achieved 95–96% accuracy using SVM and KNN.
* **Key Techniques:** Correlation Analysis, Feature Engineering, ANN.

### Employee Performance Analysis
* **Outcome:** Identified top features affecting attrition and built predictive models for high performers.
* **Key Techniques:** Feature importance analysis, Random Forest.

### Flight Price Prediction
* **Outcome:** XGBoost provided the most accurate results, outperforming linear models.
* **Key Techniques:** Time-series feature extraction, One-hot encoding.

### Heart Disease Prediction
* **Outcome:** Achieved high recall scores with Random Forest, critical for healthcare diagnostics.
* **Key Techniques:** Accuracy, Confusion Matrix analysis.

### Portuguese Bank Marketing
* **Outcome:** Optimized targeting strategy using precision-recall analysis.
* **Key Techniques:** SMOTE for class imbalance, socio-economic factor analysis.

### Sales Effectiveness Analysis
* **Outcome:** Provided strategic recommendations for sales optimization through lead scoring.
* **Key Techniques:** Decision Tree classification, segmentation.

### Texas Salary Prediction
* **Outcome:** High predictive accuracy using Gradient Boosting and Random Forest.
* **Key Techniques:** Label encoding, Feature selection.
